# SeGrup

SeGrup merupakan aplikasi mobile untuk membantu pengelolaan proyek dan tugas kelompok. Aplikasi ini menyediakan fitur pembagian tugas, pemantauan progres, pengumpulan hasil pekerjaan, validasi dan revisi tugas, serta pengelolaan anggota kelompok. SeGrup dirancang untuk mempermudah koordinasi antara Manager Proyek dan anggota agar pekerjaan lebih terorganisasi dan terpantau.
